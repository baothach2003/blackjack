# Agent instructions

The rules for any coding agent working in this repo (Codex, Claude Code or
another) live in one place: **[`CLAUDE.md`](CLAUDE.md)**. Read it fully before
starting any task, then `docs/project-plan.md` (Current Status) and
`CONSTRAINTS.md`.

This file deliberately holds no rules of its own: two copies of the same rules
drift apart. Change the rules in `CLAUDE.md` only.
